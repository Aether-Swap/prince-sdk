# Security Policy

## Supported Versions

Only the latest release of `@aether-swap/prince-sdk` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `@aether-swap/prince-sdk` seriously.

If you discover or suspect a security vulnerability, please do **not** disclose it publicly via GitHub issues, pull requests, or public forums.

Instead, please report it confidentially using **GitHub Private Vulnerability Reporting**:

1. Navigate to the repository at [https://github.com/Aether-Swap/prince-sdk](https://github.com/Aether-Swap/prince-sdk).
2. Go to the **Security** tab.
3. Under **Reporting**, click **Report a vulnerability** to open an advisory draft.
4. Provide a detailed description of the vulnerability, including reproduction steps, affected versions, and potential impact.

The maintainers will review the submission, respond through the advisory, and coordinate a fix and release.
